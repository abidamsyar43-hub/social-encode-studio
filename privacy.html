Privacy Policy

Effective date: 19 October 2026

1. About this policy

Social Encode Studio is a video encoding project under development. This page describes the current locally operated application and public information website. It will be updated before any TikTok account integration is launched.

2. Local video processing

In the current local workflow, you select media on your own computer and processing takes place on that computer. The project does not currently provide a Social Encode Studio cloud account or cloud video uploading service. Video files are not submitted to this public information website for processing.

3. Public website and hosting

This information website does not intentionally use analytics, advertising trackers or contact forms. It is hosted by GitHub Pages. The hosting provider may process standard technical information such as IP addresses and request logs under its own policies. See GitHub's privacy statement.

4. TikTok integration — not yet active

TikTok sign-in and video publishing are planned but not currently available. Before these features launch, this policy will be updated with specific details on account data, permissions, authentication token handling, storage, retention, sharing, and methods for revoking access and requesting deletion. No TikTok account credentials should be entered on this information website.

5. Changes

We will revise this policy as features and data practices change. Review the effective date above for the latest published version.
